# AlphaSync Factor Sleeve 規格書

> **鎖定日期:2026-07-03。本文件在任何回測結果被檢視之前寫定。**
> 之後對規格的任何修改都必須在「變更日誌」留下紀錄與理由,並視為一次新的試驗(計入多重檢定成本)。
> 每個設計決策標注文獻出處;沒有文獻出處的決策標注「實作約束」並說明理由。

## 0. 定位

AlphaSync 因子 sleeve 不宣稱自有 alpha。它實作文獻已驗證的溢酬:

- 橫斷面動能(Jegadeesh & Titman 1993;Fama-French UMD)
- 波動率管理(Barroso & Santa-Clara 2015)
- Value 分散(Asness, Moskowitz & Pedersen 2013 的負相關證據)

溢酬存在性的證據來自文獻(1927 年以來 + 跨市場複製),不來自本回測。
本回測的目的只有兩個:(1) 驗證管線實作正確;(2) 量測本實作相對文獻版本的稀釋程度。

## 3. 波動率管理層(BSC)

| 決策 | 規格 | 出處 |
|------|------|------|
| 波動估計 | σ̂²_m = 21 × Σ(sleeve 前 126 個交易日日報酬²)/126 | Barroso & Santa-Clara 2015 原式 |
| 權重 | w_m = min(1.0, σ_target,月 / σ̂_m) | BSC;上限 1.0 為散戶無槓桿約束 |
| 目標波動 | σ_target = 20% 年化(主規格) | 實作約束:取 NDX 長期波動量級,使該層只在高波動期作用。**穩健性申報集:{16%, 24%},兩者結果一併報告,不得擇優** |
| 縮減去向 | 現金,報酬記 0(保守,不計利息) | 實作約束 |

已知稀釋:BSC 原版可加槓桿(權重中位數 1.44),上限 1.0 砍掉「低波動期放大」的那一半,預期只保留 crash 保護。此為事前預期,寫在這裡供事後對照。

## 4. Value sleeve(可選第二 sleeve)

- **實作:持有 VTV,裸放,不做波動管理。** 理由:(1) NDX 內建 value 因子無意義(成長股指數,且缺 point-in-time 基本面資料);(2) Moreira-Muir 2017:波動管理對 value 無效,2026-07-02 自行複製亦確認(對組合加管理反而放大負溢酬)。
- **組合選項:動能/價值 = 75/25 或 50/50,月頻再平衡。** 兩者皆報告。
- 揭露義務:value 溢酬近 20 年為負(HML 2006-2026 年化 −1.16%),其納入依據是 1927 年以來與跨市場證據。此句必須出現在產品頁。

## 5. 成本

- 主報表:毛報酬。
- 副報表:單邊 10 bps × 月換手率(換手率 = 0.5×Σ|Δw|)。大型股、月頻,預期影響小,但必須量化呈現。

## 6. 驗證關卡(先過關卡,才准解讀績效)

1. **管線正確性抽查:** 已知事件對照(例:NVDA 應在 2023-2024 多數月份位於 top-20;TSLA 應在 2020 下半年進入;2022 熊市 sleeve 應大幅落後現金)。
2. **對照相關性:** sleeve 月報酬與 MTUM、QQQ 的相關係數;sleeve 對 QQQ 的 beta。申報預期:與 QQQ 相關 > 與 SPY 相關;beta 對 QQQ ≈ 1 量級。異常即回頭查管線。
3. **換手率合理性:** 月單邊換手率應在文獻動能策略量級(過高疑似訊號計算錯誤,過低疑似排名未更新)。
4. 通過後才看:報酬統計、BSC 層前後對比、value 組合對比、對 QQQ/SPY 的 alpha 回歸。

## 7. 事前預期(寫下來,防止事後合理化)

- Long-only NDX top-20 動能 sleeve 對 QQQ 的超額:預期量級 0~3%/年,t 不顯著(11.5 年樣本無檢定力,見 2026-07-03 研究日誌的檢定力計算)。
- BSC 層(cap 1.0):預期改善偏度與 MaxDD(尤其 2020-03、2022),Sharpe 改善幅度小於文獻的 1.8x(無槓桿側)。
- Value 25/50%:預期拖累近 11 年報酬、降低組合波動。
- 若結果與預期方向相反(例如 BSC 層惡化回撤),優先懷疑實作錯誤,其次才是解讀。
